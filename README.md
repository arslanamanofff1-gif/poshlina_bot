# ⚖️ Калькулятор госпошлины — Telegram Mini App

Считает государственную пошлину в судах общей юрисдикции и Верховном Суде РФ по ст. 333.19, 333.20, 333.36, 333.40 НК РФ (ред. 259-ФЗ; для заявлений и жалоб, поданных после 08.09.2024).

- Все виды требований из п. 1 ст. 333.19 и особые случаи из ст. 333.20: развод с разделом имущества, последствия недействительности, залог, судебный приказ, третейские решения и др.
- Результат по инстанциям: первая, апелляция (частная жалоба), кассация в КСОЮ, Верховный Суд (кассация и надзор).
- Льготы по ст. 333.36: полное освобождение, освобождение при цене иска до 1 млн ₽, единственное жильё (70%).
- Доплата при увеличении иска и возврат при уменьшении.
- Возврат 70/50/30% при мировом соглашении, отказе от иска или его признании.

Сервер не нужен: весь расчёт идёт на телефоне пользователя. Приложение бесплатно размещается на GitHub Pages и не засыпает.

## Файлы

- `index.html` — интерфейс
- `calc.js` — правила расчёта; при изменении закона правится только этот файл

## Запуск за 10 минут

### 1. Выложите на GitHub Pages
1. На github.com создайте репозиторий `poshlina-bot`. Видимость **Public**: для бесплатного GitHub Pages это обязательно.
2. Нажмите **uploading an existing file**, перетащите `index.html`, `calc.js`, `README.md` и нажмите **Commit changes**.
3. Откройте **Settings** → **Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** и нажмите **Save**.
4. Через 1–2 минуты вверху страницы появится адрес вида `https://ваш-логин.github.io/poshlina-bot/`. Откройте его и проверьте, что калькулятор работает.

### 2. Подключите к боту
1. В **@BotFather** отправьте `/newbot` и создайте бота, например «Госпошлина в суд».
2. Отправьте `/mybots`, выберите бота, затем **Bot Settings** → **Menu Button** → **Configure menu button**. Вставьте адрес с GitHub Pages и введите текст кнопки: `Рассчитать`.
3. Там же откройте **Bot Settings** → **Configure Mini App** → **Enable Mini App** и вставьте тот же адрес. В профиле бота появится кнопка «Открыть».
4. Отправьте `/setdescription` и введите текст, который пользователь увидит до нажатия Start, например: «Рассчитаю госпошлину для суда общей юрисдикции: первая инстанция, апелляция, кассация, ВС РФ. Нажмите кнопку „Рассчитать“».
5. Необязательно: отправьте `/newapp`, чтобы получить прямую ссылку `t.me/ваш_бот/calc`. Её удобно давать в канале.

## Как обновить размеры пошлины

Все суммы находятся в `calc.js`: шкала `SCALE`, массив `TYPES` (твёрдые суммы по каждому подпункту) и `APPEALS` (жалобы). Откройте файл на GitHub, нажмите карандаш, внесите правку и нажмите **Commit changes**. Сайт обновится за минуту.
